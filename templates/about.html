Project Overview

HepatoSense is a clinical decision support system for liver disease detection built on an explainable ensemble machine learning pipeline. It combines six diverse classifiers into a soft-voting ensemble, then applies post-hoc global explainability methods to make every prediction transparent and clinically interpretable.

The system is designed around the principle that accuracy alone is insufficient in a medical context — clinicians need to understand why a model made a particular prediction before acting on it.
